# 線東大眾護理之家 — F 班自動排定系統

把 T 班一鍵轉成上色、補人頭、合規的 F 班，並接著自動產出約束評估記錄單與住民日常生活照護表。
純本機執行、瀏覽器操作、資料不外流。

## 快速開始

### Mac：雙擊 `一鍵啟動.command`

第一次會自動建立獨立環境並安裝套件（約 1 分鐘），之後每次啟動只要幾秒。
瀏覽器會自動打開，預設密碼 `dazhong123`（請改）。要結束就關掉終端機視窗。

> 從網路下載的檔案，第一次雙擊若被系統擋下，改成**按住 Control 點一下 →「打開」**即可。
> 啟動檔會自動避開被佔用的埠（macOS 的 AirPlay 接收器會佔用 5000），依序試 5050、5051…

### 或者自己用指令

```bash
pip install -r requirements.txt
python app.py           # 瀏覽器開 http://127.0.0.1:5000（預設密碼 dazhong123，請改）
```

macOS 上 5000 埠常被 AirPlay 接收器佔用（連進去會回 403），改用 `FBAN_PORT=5050 python app.py`。

## 網頁功能

- **首頁（自動產生）**：上傳 護理／台籍照服／外籍照服 T 班（xlsx 或 PDF）＋月份 → 產生 F 班，
  顯示納入人數、設立標準缺口、補人頭數、勞基法提示，可下載 F 班與檢核報告。
- **上傳 F 班產文件**：已有 F 班（含手動微調過的）→ 直接上傳 → 進文件工作流。
- **文件工作流**：一鍵產出約束評估記錄單（範本內建）；上傳照護表範本產出住民日常生活照護表。

## 只維護一個檔：後台設定.xlsx

| 分頁 | 內容 |
|---|---|
| 設定 | 年月、每班最低人力、目標人數、各種上限 |
| 人員主檔 | 姓名/區塊/帳號/核章人員(人頭)/樓層/資格/適用班別碼打勾 |
| 班別碼對照、樓層顏色規則 | T碼→F碼、(區塊×班別×樓層)→底色 |
| 人頭池、非人頭其他工作、排除人員 | 補班人頭、不補班者、不進F班者 |
| 年度行事曆、國定假日日期 | 每月例/休/國配額；國定假日確切日期(選填) |
