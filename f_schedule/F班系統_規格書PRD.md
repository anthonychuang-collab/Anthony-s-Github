# 線東大眾護理之家 — F 班自動排定系統 規格書（PRD）

**機構**：線東大眾護理之家（大眾長照體系）
**版本**：v2.0
**狀態**：已實作並以 115.07 / 115.08 真實資料驗證；自動化測試 51 項全綠

---

## 1. 一句話說清楚做什麼

> 讀入護理／台籍照服／外籍照服的 **T 班**，一鍵產出**上好色、補好人頭、符合勞基法與設立標準**的 **F 班**；並可**接著自動產出**約束評估記錄單與住民日常生活照護表。整套跑在機構自己的電腦、用瀏覽器操作、資料不外流。

---

## 2. 為什麼要做這個

F 班是機構核心稽核文件（人頭核章對照、照護表核章對應、勞基法與設立標準佐證），過去全靠人工從 T 班複製、改人頭、逐格上色、手動補班、盤點人力與例假，一份耗時且易錯。下游的約束表、照護表又要再把每天的值班姓名一格格抄進 Word。本系統把「T 班 → F 班 → 下游文件」整條流程自動化，並在每一步做勞基法與設立標準的自動檢核，讓承辦把時間花在審查例外，而不是重複勞動。

## 3. 使用者故事與驗收標準（核心）

### US-1 護理 T 班轉 F 班（轉碼＋上色）
```
身為 排班承辦
我想把護理 T 班一鍵轉成 F 班護理區塊
這樣不用逐格改碼與上色

驗收：
- Di/2Di/3Di→D4x；E→Ex；N→Nx；R→例/休（依配額）
- 依樓層上色：2F綠 3F藍 5F紅；小夜橘 大夜灰
- 對照實際手排 F 班，護理班別碼相符率 ≥95%（實測 95~100%）
```

### US-2 人頭改名與核章對應
```
身為 稽核承辦
我想讓使用他人牌照的同仁在 F 班顯示正確核章人員
驗收：後台可維護核章人員(人頭牌照)；F 班核章欄顯示牌照持有人、
      排班欄顯示實際同仁（例：陳詡善使用陳淑萍牌照）
```

### US-3 外籍照服碼轉換與上色
```
驗收：D3a/N5a/D5b… → Dx/Nx/Ex（去 a/b，樓層以底色表示）；
      兩種寫法都吃(D3a 與 2Da)；C/K/Ep/Dp 不計入照護人力
```

### US-4 自動補人頭達設立標準
```
身為 機構負責人
我想在人力不足處自動用人頭池補班
驗收：每班≥7人；每班護理≥1；夜間台籍照服≥1；
      遵守三班順排、可用起迄日(高偲芸8/20起)；
      實測 115.08 三來源：缺口 82 → 0
```

### US-5 例/休/國 依機構年度行事曆
```
驗收：後台〈年度行事曆〉每月配額(例:115.08=5例5休0國)；
      每人休息日依配額拆成例/休/國，例假數嚴守配額(實測每人恰5例)；
      跨年度共用，每年加 12 列即可、免改程式
```

### US-6 少休機制（人力真的不足時）
```
驗收：人頭池排滿仍不足時，安排人頭休假日出勤補人力，
      但硬守每14天≥2例假（不可違反），班種欄標記「少休N天」；
      實測月底 3 小夜缺口由少休補滿、缺口 3→0、無新增例假違規
```

### US-7 F 班來源二選一（自動產生 / 上傳現成）
```
身為 排班承辦（有時會手動微調 F 班）
我想選擇「用 T 班自動產 F 班」或「直接上傳我已有的 F 班」
這樣手動調整過的 F 班也能接著產下游文件

驗收：
- 路徑一：上傳 T 班 → 產 F 班 → 進文件工作流（用系統內部資料）
- 路徑二：首頁「上傳 F 班產文件」→ 上傳本系統格式 F 班 xlsx
  （含手動微調）→ 依儲存格底色讀回樓層/班別/核章 → 進工作流
- 「寫出→讀回」往返測試：樓層/班別/核章姓名還原正確
```

### US-8 產出約束評估記錄單
```
驗收：2F/3F/5F 各一份 Word；年月與日期已填；
      每 2 小時時段簽名欄以淺灰預填當班護理核章姓名
      （前4列大夜、中4列白班、後4列小夜）；範本內建、一鍵產出
```

### US-9 產出住民日常生活照護表
```
驗收：把每日「白班護理／白班照服(台籍)／夜班照服(台籍)」姓名
      填入你們的照護表 Word 範本(上傳各樓層範本)；
      照服欄只取台籍照服員(核章者)；對照手填版白班照服相符率 78%
```

### US-10 自動檢核報告
```
驗收：設立標準(逐日列缺人/缺護理/缺台籍照服)；
      勞基法(例假每14天≥2、三班順排)；PT兼職不誤報例假；
      能抓出「T 班本身」的例假違規供回頭修正
```

### US-11 純後台維運（不需工程師）
```
驗收：只編輯〈後台設定.xlsx〉即可調整所有規則：
      設定、人員主檔(含適用班別碼打勾)、班別碼對照、樓層顏色規則、
      人頭池、非人頭其他工作、排除人員、年度行事曆、國定假日日期
```

### US-12 機構內多台連線、資料不外流
```
驗收：本機執行、預設綁 0.0.0.0；同網段電腦用 http://主機IP:5000 連入；
      需輸入存取密碼(FBAN_PASSWORD)；全程不呼叫外部網路；
      不做 port forwarding 即只在內網可見
```

### US-13 Mac 主機免安裝執行檔＋開機自動啟動
```
驗收：mac/ 內雙擊腳本即可：打包成免安裝執行檔、設定開機自動啟動
      （launchd，當掉自動重開）；接手/換機零技術負擔
```

## 5. 系統架構

```
瀏覽器(登入) ──┬─ 路徑一：上傳T班 → generate_fban → F班xlsx + 檢核報告
              └─ 路徑二：上傳F班xlsx → read_fban(讀底色) ─┐
                                                          ↓
                              文件工作流 ── 約束表(docgen→gen_form)
                                        └─ 照護表(docgen→fill_care_record，需範本)
規則與主檔全部讀自 後台設定.xlsx（純 Excel 維護）
```

**後台資料模型（後台設定.xlsx）**：設定／人員主檔／班別碼對照／樓層顏色規則／人頭池／非人頭其他工作／排除人員／年度行事曆／國定假日日期。

**相依**：openpyxl、pdfplumber、flask、python-docx（文件產生不需 LibreOffice 與字型；標楷體於 Mac 開檔時算繪）。

## 6. 已知限制與後續（Backlog）

- **例假 vs 月配額邊界**：少數同仁 T 班休假過度集中，在月配額下某14天湊不到2例，報告會列出供人工調整 T 班休假分布。
- **上傳 F 班格式**：目前支援「本系統產生的 F 班版面」（依底色判樓層）；純手做的舊 Excel 版面若要支援，需另寫對應擷取邏輯。
- **照護表夜班照服相符率**：受上游 F 班照服/人頭指派差異影響；提供完整台籍照服 T 可再提升。
- **環境永續**：雲端測試環境為暫時性；正式使用請採 Mac 主機部署，程式與資料留在本機。
