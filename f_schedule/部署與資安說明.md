# 部署與資安說明（區網內部、資料不外流）

## 原理
系統跑在機構自己的一台電腦(主機)上，全部運算本機完成、不呼叫任何外部網路；
上傳的班表與產出只存在主機。其他電腦透過機構內部區網連進來，資料未離開機構。
**只要不在路由器對連接埠做 port forwarding，外網就看不到它。**

## 步驟（主機端）
1. `pip install -r requirements.txt`（選裝 `pip install waitress` 多人較穩）
2. 設密碼：Mac/Linux `export FBAN_PASSWORD="你的密碼"`；Windows `set FBAN_PASSWORD=你的密碼`
3. `python app.py`（啟動後畫面印出可連網址）
4. 其他電腦瀏覽器輸入 `http://主機IP:5000` → 輸入密碼

## 資安清單
- ❌ 不要對 5000 埠做 port forwarding（保持只在內網可見）
- ✅ 用 FBAN_PASSWORD 設強密碼、定期更換（勿用預設 dazhong123）
- ✅ 主機防火牆僅允許內網段連入 5000 埠；建議主機固定內網 IP
- `runtime/` 是上傳/產出暫存，可定期清空；`後台設定.xlsx` 含人員資料，比照人事資料保管

## 環境變數
| 變數 | 預設 | 說明 |
|---|---|---|
| FBAN_PASSWORD | dazhong123 | 存取密碼（請改） |
| FBAN_HOST | 0.0.0.0 | 127.0.0.1=只限本機 |
| FBAN_PORT | 5000 | 連接埠 |
| FBAN_SECRET | 隨機 | 登入 session 金鑰(設固定值可免重登) |
