---

## 1. 這是什麼

線東大眾護理之家（大眾長照體系）的 **F 班自動排定系統**。
把護理／台籍照服／外籍照服的 **T 班**（原始班表）轉成上好色、補好人頭、
符合勞基法與設立標準的 **F 班**，再自動產出下游稽核文件：

- **約束評估記錄單**（2F/3F/5F 各一份 Word＋PDF，範本內建）
- **住民日常生活照護表**（需機構的 Word 範本，可存在後台長期沿用）

純本機執行、瀏覽器操作、資料不外流。使用者是機構承辦，**不是工程師**，
Mac 上雙擊 `一鍵啟動.command` 就能開。

詳細規格見 `F班系統_規格書PRD.md`（v2.2），開發慣例見 `CLAUDE.md`。

## 3. 兩條資料流（很重要）

```
路徑一  上傳 T 班 → generate_fban.run() → F 班 xlsx + 檢核報告 → 文件工作流
路徑二  上傳現成 F 班 xlsx → read_fban.load()（讀底色還原）→ 文件工作流
```

**同一件事在兩條路徑上都要改**，這是本專案最常見的 bug 來源。
已有迴歸測試鎖住一致性：`test_head_name_same_on_both_paths`。

## 5. 機構的業務規則（已確認，不要自己改）

- **核章人員欄只給真正使用他人牌照者**。目前主檔中**無人**填此欄：
  - 陳詡善：原名陳淑萍，是**改名**，不是借牌
  - 洪瑞輝：核章人員欄原**誤填**王淑環，王淑環這個人不存在
- 核章人員必須是人員主檔裡真實存在的人；查無此人一律忽略並印本人姓名。
- 約束表大夜**跨午夜**：第 D 天凌晨的大夜是班表第 (D-1) 天那位；
  第 1 天取上月最後一天（上傳檔含上月分頁時自動帶入，可手動覆寫）。
- 同日同樓層多位白班時，跳過護理長（班種 D0）取實際責任護士。
- 樓層靠**儲存格底色**判定：2F綠 FF70AD47／3F藍 FF5B9BD5／5F紅 FFFF2F92。
- 規則不寫死在程式：顏色、班別碼、人頭池、行事曆配額全在 `後台設定.xlsx`。

## 6. 待辦（使用者尚未拍板）

1. **後台網頁編輯頁面**（使用者主動提出）
   目前改人員資料要開 `後台設定.xlsx`，承辦覺得不友善，也確實出過錯。
   想在瀏覽器裡直接編輯、存檔即生效、自動備份原檔。
   **範圍未定**，使用者問過但還沒選。建議：**先做「人員主檔」一張**
   （姓名／區塊／帳號／核章人員／樓層／班別碼勾選／備註），能用了再擴充。
2. **人員姓名尚未逐日核對** — 使用者說要核對 10 月照護表的人名，還沒回報結果。
3. 使用者手上若還有舊的 F 班檔案，走上傳路徑時會看到「已失效的核章人員」提示；
   文件是對的，重產一次 F 班即可消失。

```bash
cd f_schedule
python3 tests/test_fban.py        # 必須 160/160 全綠才開始改
```

**工作慣例（使用者很在意）**

- 改任何 code 後都要跑測試，報告實際數字，不要只說「應該沒問題」。
- 修 bug 時**先驗證真正的根因**（讀檔案、跑實驗），不要用猜的下結論。
- 加修正時**同時加迴歸測試**，並把修正拿掉重跑一次，確認測試真的會轉紅。
- 使用者端與 repo 常常版本分岔：**每次收到使用者上傳的 zip，先 diff 比對**，
  分辨哪些是新功能、哪些是倒退，不要整包覆蓋（已發生過三次）。
- 使用者不是工程師：說明要具體到「點哪裡、看到什麼」，不要只給指令。

## 8. 檔案導覽

```
fban/                 核心邏輯（無 web 相依）
├─ config.py          讀 後台設定.xlsx；核章人員查無此人會在此忽略
├─ codes.py           班別碼解析
├─ tsheet.py          讀 T 班 xlsx（姓名/帳號欄認標題；日期列支援 1 與 10/1(四)）
├─ tsheet_pdf.py      讀 T 班 PDF
├─ convert.py         T→F 轉換：碼、例/休/國配額、樓層上色
├─ coverage.py        設立標準＋勞基法檢核
├─ fillin.py          自動補人頭（含少休）
├─ writer.py          寫出 F 班 xlsx
├─ read_fban.py       讀回 F 班（機構原生多分頁＋本系統版面）
├─ pdfexport.py       docx→PDF（LibreOffice）
└─ docgen.py          產下游文件
generate_fban.py      CLI 主流程 run()
app.py                Flask：登入／產F班／上傳F班／文件工作流／後台範本設定
docskills/            約束表與照護表的 docx 引擎
tests/test_fban.py    自製零依賴測試（160 項）
後台設定.xlsx         唯一要維護的主檔
一鍵啟動.command      Mac 雙擊啟動
```
