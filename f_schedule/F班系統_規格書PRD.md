# 線東大眾護理之家 — F 班自動排定系統 規格書（PRD）

**機構**：線東大眾護理之家（大眾長照體系）
**版本**：v2.2
**狀態**：已實作並以 115.07 / 115.08 / 115.09 真實資料驗證；自動化測試 79 項全綠

---

## 1. 一句話說清楚做什麼

> 讀入護理／台籍照服／外籍照服的 **T 班**，一鍵產出**上好色、補好人頭、符合勞基法與設立標準**的 **F 班**；並可**接著自動產出**約束評估記錄單與住民日常生活照護表。整套跑在機構自己的電腦、用瀏覽器操作、資料不外流。

---

## 2. 為什麼要做這個

F 班是機構核心稽核文件（人頭核章對照、照護表核章對應、勞基法與設立標準佐證），過去全靠人工從 T 班複製、改人頭、逐格上色、手動補班、盤點人力與例假，一份耗時且易錯。下游的約束表、照護表又要再把每天的值班姓名一格格抄進 Word。本系統把「T 班 → F 班 → 下游文件」整條流程自動化，並在每一步做勞基法與設立標準的自動檢核，讓承辦把時間花在審查例外，而不是重複勞動。

## 3. 使用者故事與驗收標準（核心）

### US-1 護理 T 班轉 F 班（轉碼＋上色）
```
身為 排班承辦
我想把護理 T 班一鍵轉成 F 班護理區塊
這樣不用逐格改碼與上色

驗收：
- Di/2Di/3Di→D4x；E→Ex；N→Nx；R→例/休（依配額）
- 依樓層上色：2F綠 3F藍 5F紅；小夜橘 大夜灰
- 對照實際手排 F 班，護理班別碼相符率 ≥95%（實測 95~100%）
```

### US-2 人頭改名與核章對應
```
身為 稽核承辦
我想讓使用他人牌照的同仁在 F 班同時看得到牌照持有人與實際同仁
驗收：後台可維護核章人員(人頭牌照)；F 班「核章人員」欄顯示牌照持有人、
      「人員」欄顯示實際同仁（例：陳詡善使用陳淑萍牌照）

下游文件（約束表／照護表）印的姓名，目前依 F 班來源而不同：
- 路徑一（T 班自動產生）：印牌照持有人（陳淑萍）—— 來自後台主檔的核章人員欄
- 路徑二（上傳 F 班）：印名冊欄實際同仁（陳詡善），核章人員欄另存為 stamp 供參考
  ※ 兩條路徑姓名不一致，待機構確認統一採哪一種，見第 6 節 Backlog
```

### US-3 外籍照服碼轉換與上色
```
驗收：D3a/N5a/D5b… → Dx/Nx/Ex（去 a/b，樓層以底色表示）；
      兩種寫法都吃(D3a 與 2Da)；C/K/Ep/Dp 不計入照護人力
```

### US-4 自動補人頭達設立標準
```
身為 機構負責人
我想在人力不足處自動用人頭池補班
驗收：每班≥7人；每班護理≥1；夜間台籍照服≥1；
      遵守三班順排、可用起迄日(高偲芸8/20起)；
      實測 115.08 三來源：缺口 82 → 0
```

### US-5 例/休/國 依機構年度行事曆
```
驗收：後台〈年度行事曆〉每月配額(例:115.08=5例5休0國)；
      每人休息日依配額拆成例/休/國，例假數嚴守配額(實測每人恰5例)；
      跨年度共用，每年加 12 列即可、免改程式
```

### US-6 少休機制（人力真的不足時）
```
驗收：人頭池排滿仍不足時，安排人頭休假日出勤補人力，
      但硬守每14天≥2例假（不可違反），班種欄標記「少休N天」；
      實測月底 3 小夜缺口由少休補滿、缺口 3→0、無新增例假違規
```

### US-7 F 班來源二選一（自動產生 / 上傳現成）
```
身為 排班承辦（有時會手動微調 F 班）
我想選擇「用 T 班自動產 F 班」或「直接上傳我已有的 F 班」
這樣手動調整過的 F 班也能接著產下游文件

驗收：
- 路徑一：上傳 T 班 → 產 F 班 → 進文件工作流（用系統內部資料）
- 路徑二：首頁「上傳 F 班產文件」→ 上傳 F 班 xlsx（含手動微調）→ 進工作流
  可讀兩種版面：
    a) 機構原生多分頁班表：依月份自動挑對分頁（114.12…115.09）
    b) 本系統產生的 F 班版面
  欄位靠標題自動對位（帳號／核章人員／區塊名／班種＋日期列）；
  樓層由儲存格底色判定，含 Excel 佈景主題色(theme color)先解析成 RGB 再比對
- 防呆：只讀到極少人員（護理<2）即中止並說明，不產出空白表單
- 「寫出→讀回」往返測試：樓層/班別/姓名/區塊還原正確
  （三個區塊須各自還原，不可全部落到護理）
```

### US-8 產出約束評估記錄單
```
驗收：2F/3F/5F 各一份 Word（另附 PDF，見 US-14）；年月與日期已填；
      每 2 小時時段簽名欄以淺灰預填當班護理姓名
      （前4列大夜、中4列白班、後4列小夜）；範本內建、一鍵產出

大夜跨午夜對位：約束表第 D 天 00:00~08:00 的大夜，是「班表第 (D-1) 天大夜」
那位護理值到隔天早上，故大夜一律往前推一天。
第 1 天的大夜取上月最後一天大夜：上傳檔含上月分頁時自動帶入，
工作流也可手動填寫／覆寫。

同日同樓層有多位白班時，跳過護理長（班種 D0）取實際責任護士。
```

### US-9 產出住民日常生活照護表
```
驗收：把每日「白班護理／白班照服(台籍)／夜班照服(台籍)」姓名
      填入機構的照護表 Word 範本；照服欄只取台籍照服員；
      對照手填版白班照服相符率 78%

範本來源：後台範本設定（`/settings/templates`）各樓層各存一份，之後每月自動沿用；
工作流當次上傳＝臨時覆蓋該樓層。範本存於主機 `後台範本/`。

版面：責任護士列高度取各姓名列的最大值，不會比照服員列矮；
      姓名列先整列清空再填當月有效日，故 30 天月份的第 31 欄、
      或範本右側多出的空欄一律留白，不會殘留上月姓名。
```

### US-10 自動檢核報告
```
驗收：設立標準(逐日列缺人/缺護理/缺台籍照服)；
      勞基法(例假每14天≥2、三班順排)；PT兼職不誤報例假；
      能抓出「T 班本身」的例假違規供回頭修正
```

### US-11 純後台維運（不需工程師）
```
驗收：只編輯〈後台設定.xlsx〉即可調整所有規則：
      設定、人員主檔(含適用班別碼打勾)、班別碼對照、樓層顏色規則、
      人頭池、非人頭其他工作、排除人員、年度行事曆、國定假日日期
```

### US-12 機構內多台連線、資料不外流
```
驗收：本機執行、預設綁 0.0.0.0；同網段電腦用 http://主機IP:5000 連入；
      需輸入存取密碼(FBAN_PASSWORD)；全程不呼叫外部網路；
      不做 port forwarding 即只在內網可見
```

### US-13 Mac 主機免安裝執行檔＋開機自動啟動
```
驗收：雙擊 `一鍵啟動.command` 即可啟動：首次自動建立獨立環境並安裝套件，
      自動避開被佔用的埠（macOS 的 AirPlay 接收器佔用 5000，會回 403），
      自動開瀏覽器；出錯時視窗停住顯示原因。
      mac/ 內另有雙擊腳本：打包成免安裝執行檔、設定開機自動啟動
      （launchd，當掉自動重開）；接手/換機零技術負擔
```

### US-14 文件 PDF 定版
```
身為 稽核承辦
我想讓產出的文件在別台電腦開啟時版面不會跑掉
驗收：約束表與照護表在 Word 之外同時附一份 PDF；
      由主機的 LibreOffice(soffice) 轉檔，標楷體等字型由主機提供；
      主機未安裝 LibreOffice 時只給 Word、不報錯（降級而非失敗）
```

## 5. 系統架構

```
瀏覽器(登入) ──┬─ 路徑一：上傳T班 → generate_fban → F班xlsx + 檢核報告
              └─ 路徑二：上傳F班xlsx → read_fban(挑月份分頁/標題對位/讀底色) ─┐
                                                                              ↓
                              文件工作流 ── 約束表(docgen→gen_form)   ─┬→ +PDF
                                        └─ 照護表(docgen→fill_care_record) ┘  (pdfexport→soffice)
                                                     ↑
                                        後台範本設定 /settings/templates
規則與主檔全部讀自 後台設定.xlsx（純 Excel 維護）；照護表範本存 後台範本/
```

**後台資料模型（後台設定.xlsx）**：設定／人員主檔／班別碼對照／樓層顏色規則／人頭池／非人頭其他工作／排除人員／年度行事曆／國定假日日期。

**相依**：openpyxl、pdfplumber、flask、python-docx、waitress。
Word 文件產生不需 LibreOffice 與字型（標楷體於 Mac 開檔時算繪）；
**PDF 定版**才需要主機安裝 LibreOffice，未安裝則只給 Word。

## 6. 已知限制與後續（Backlog）

- **例假 vs 月配額邊界**：少數同仁 T 班休假過度集中，在月配額下某14天湊不到2例，報告會列出供人工調整 T 班休假分布。
- **下游文件姓名兩條路徑不一致**（待機構決定）：同一位人頭同一個月，走「T 班自動產生」印牌照持有人（陳淑萍），走「上傳 F 班」印名冊欄實際同仁（陳詡善）。需確認稽核上要統一採哪一種，再把另一條路徑對齊。
- **上傳 F 班格式**：已支援機構原生多分頁班表與本系統版面；樓層仍依底色判定，故底色若與後台〈樓層顏色規則〉不符會判不出樓層（夜班照服的相近色階已另補常見對照）。
- **照護表夜班照服相符率**：受上游 F 班照服/人頭指派差異影響；提供完整台籍照服 T 可再提升。
- **環境永續**：雲端測試環境為暫時性；正式使用請採 Mac 主機部署，程式與資料留在本機。
